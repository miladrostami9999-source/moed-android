# موعد (Moed)

اپلیکیشن آفلاین مدیریت اقساط، وام، اجاره و پرداخت‌های دوره‌ای.

## اصول پروژه

- رایگان و بدون سرور اجباری
- ذخیره اطلاعات در Room روی گوشی
- ذخیره رسیدها با Storage Access Framework
- بکاپ و بازیابی محلی رمزگذاری‌شده
- ورود Google اختیاری؛ برنامه بدون حساب هم کار می‌کند
- رابط فارسی و تاریخ شمسی
- ساخت APK با GitHub Actions

## ساخت APK

هر Push روی شاخه `main` یک Debug APK در بخش Actions تولید می‌کند. برای ساخت محلی:

```bash
gradle assembleDebug
```

## وضعیت فعلی

اسکلت فنی، تم، صفحه خانه، فرم اولیه افزودن پرداخت، مدل Room و CI آماده است. انتخاب‌گر کامل شمسی، رسیدها، بکاپ و زمان‌بندی اعلان‌ها در گام‌های بعدی تکمیل می‌شوند.
